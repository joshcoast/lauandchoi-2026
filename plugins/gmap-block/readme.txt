Easily Embed Google map in Gutenberg editor without any API key.

== Description ==
Gmap Block is a custom Gutenberg block plugin to display Google map in Gutenberg editor without using any API key. Simply drag and drop the block to add the Google map easily. So, display Google map quickly without any hassles, and customize it as per your need.

### Key Features 
* Easy to use
* Simple, light-weight and fast
* Embed Google map without API Key
* Responsive Height
* Different Map Types support
* Customization Options 
* No third-party dependencies.

### What you get free

* Embed a Google map with no API key and no setup
* Roadmap, satellite, terrain and hybrid map types
* Responsive height, zoom level
* Border, radius, padding and margin controls

### What Gmap Block Pro adds

* **Multiple locations** on one map, each with its own details
* **Custom markers** — your own pin colours or an SVG icon
* **Info windows** attached to any marker
* **Location cards** that pan and zoom the map when clicked
* **Map styling** — dark mode, muted palettes, hidden points of interest
* **Interaction control** — stop the map hijacking page scroll
* **Driving directions** between two points
* **SVG world map** coloured by your own data
* Priority support and automatic updates

### Gmap Block Pro

Pro turns the embed into a real map you control. Add as many locations as you need, give each one its own marker and info window, restyle the map to match your theme, and stop it hijacking the page scroll.

Pro needs a free Google Maps API key. The plugin walks you through creating one and includes a **Test this key** button that tells you exactly which Google API still needs enabling, so you are never left guessing at a blank map.

[Get Gmap Block Pro &rarr;](https://gmap.gutenbergkits.com/)

== Installation ==
1. Upload the plugin files to the `/wp-content/plugins/gmap-block` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress

== Frequently Asked Questions ==

= Do I need a Google Maps API key? =

Not for the free plugin. It embeds the map the same way Google's own "share map" embed does, so there is nothing to configure. An API key is only needed for Gmap Block Pro, which uses the Google Maps JavaScript API for interactive features.

= My Pro map is blank. What is wrong? =

Almost always the Google Cloud project behind your key does not have the right APIs switched on. Open Settings &rarr; Gmap Block and press **Test this key** — it reports whether Google accepted the key and whether Places API (New) responded, so you know exactly what to enable.

= Can I put more than one location on a map? =

Not in the free plugin — the embed supports a single location. Multiple locations, each with its own marker and info window, are a Pro feature.

= Can I change the colours of the map itself? =

The free plugin styles the frame around the map (border, radius, spacing). Restyling the map surface — dark mode, muted colours, hiding points of interest — requires the Maps JavaScript API and is a Pro feature.

= Does the block work with block themes and Full Site Editing? =

Yes. It is a standard block and works in posts, pages, templates, template parts and patterns.
